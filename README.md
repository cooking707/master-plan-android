# 마스터 플랜 (안드로이드)

캘린더 일정과 할 일을 **잠금화면 배경**에 그려 주는 앱입니다. 잠금화면만 켜도 오늘 할 일 네 칸과 올해 진행률이 보입니다.
아이폰용 '마스터 플랜'을 안드로이드(갤럭시)로 옮긴 판입니다.

## 갤럭시에 설치하기 (5분)

1. 휴대폰 인터넷에서 아래 주소를 엽니다.
   **https://github.com/cooking707/master-plan-android/releases/latest/download/master-plan.apk**
2. 받은 `master-plan.apk`를 엽니다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 돌아와 **설치**를 누릅니다.
   (Play 프로텍트가 "확인되지 않은 앱"이라고 하면 **세부정보 → 무시하고 설치**)
4. 마스터 플랜을 열고 **캘린더 권한 → 허용**.
5. **설정 탭 → 할 일 네 칸**에서 칸마다 "연결한 캘린더"를 고릅니다.
   고른 캘린더의 오늘 일정이 그 칸의 할 일로 들어오고, 칸 이름과 색도 캘린더를 따라갑니다.
6. **잠금화면 탭 → 지금 잠금화면에 적용**. 휴대폰을 잠갔다 켜서 확인합니다.
7. (권장) **설정 탭 → 배터리 최적화 해제**. 갤럭시가 백그라운드 갱신을 멈추지 않게 합니다.

구글 캘린더 일정은 휴대폰에 구글 계정이 추가돼 있으면 자동으로 보입니다
(갤럭시 설정 → 계정 및 백업 → 계정 관리 → 구글 계정 → 계정 동기화 → 캘린더 켜기).

## 언제 잠금화면이 바뀌나

- 30분마다, 매일 0시 1분, 캘린더 일정이 바뀔 때(약 20초 뒤), 앱에서 무언가 바꿀 때, 앱을 나갈 때
- 그린 내용이 지난번과 같으면 다시 쓰지 않습니다.

## 쓰는 법

- **할 일 탭**: 네 칸. 동그라미를 누르면 완료. 캘린더에서 온 항목(달력 아이콘)은 앱 안에서만 완료로 표시하고 캘린더 일정은 건드리지 않습니다.
- **캘린더 탭**: 앞으로 3주 일정.
- **잠금화면 탭**: 템플릿 7종(대표님 선호, 오늘 일정 + 연간 진행, 매트릭스, 캘린더, 오늘 타임라인, 오늘 + 연간 진행, 체크리스트), 배경 6색, 카드 시작 높이(시계와 겹치면 늘리기).

## 업데이트

같은 설치 주소에서 다시 받아 설치하면 됩니다(할 일·설정 유지). 새 버전이 올라오면 앱의 설정·잠금화면 탭에 "새 버전이 있어요" 카드가 뜹니다.

## 잠금화면이 안 바뀔 때

- 갤럭시 설정 → 잠금화면 → **배경화면 서비스(다이내믹 잠금화면)**를 "사용 안 함"으로.
- 배터리 최적화 해제 후 앱의 **지금 잠금화면에 적용**을 한 번 누르기.
- 잠금화면 탭에 "오류:" 문구가 보이면 그 내용을 알려 주세요.

## 개발자용 (클로드 코드에서)

```bash
git clone https://github.com/cooking707/master-plan-android.git
cd master-plan-android
./gradlew assembleDebug        # JDK 17, Android SDK 35 필요
adb install -r app/build/outputs/apk/debug/app-debug.apk   # 휴대폰 USB 디버깅 켠 뒤
```

- `main`에 올리면 GitHub Actions가 서명된 APK를 만들어 릴리스에 올립니다(위 설치 주소가 최신판을 가리킴).
- 디버그 APK와 릴리스 APK는 서명이 달라서 서로 덮어 설치되지 않습니다. 평소에는 릴리스 주소로 설치하세요.
- 코드: `Plan.kt`(캘린더 읽기·스냅샷), `Render.kt`(잠금화면 그리기), `Updater.kt`(적용·자동 갱신), `ui/`(화면).
